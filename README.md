# E-commerce-Retail-System
This project focuses on designing and implementing a Data Warehouse and Business Intelligence solution using the Brazilian E-Commerce Public Dataset by Olist. It integrates heterogeneous data sources (SQL Server, CSV, and JSON) through an SSIS-based ETL process into a dimensional Data Warehouse using a star schema.

The project also includes the development of four SQL Data Marts and interactive Power BI dashboards to analyse sales performance, customer behaviour, product trends, geographical patterns, and delivery performance, supporting data-driven business decision-making.
